# 音频起始编辑工具（GUI）

这是一个仿 iOS 风格的 Python GUI 音频编辑工具，支持：

- 删除音频开头的一小段
- 在音频开头增加一小段静音
- 时间精度到 `0.01` 秒
- 拖拽导入音频，或点击区域打开自定义文件浏览弹窗
- 导出时自定义文件名，并选择是否转换格式
- 输出到运行目录 `Output` 文件夹，完成后自动打开文件夹

## 支持格式

导入/导出支持（受 ffmpeg 能力影响）：

- `mp3`
- `wav`
- `flac`
- `ogg`
- `m4a`
- `aac`
- `wma`
- `aiff`
- `opus`

## 安装依赖（下载到当前目录）

在项目目录运行：

```powershell
./install_deps.ps1
```

该脚本会把依赖安装到本地 `_deps` 目录，不污染系统环境。

## 启动

```powershell
python app.py
```

## 说明

- 程序会优先加载本地 `_deps` 目录的依赖。
- 程序会优先使用系统 `ffmpeg`；如果没有，会尝试使用 `imageio-ffmpeg` 自带的 ffmpeg。
- 如果导出同名文件已存在，会自动追加 `_1`、`_2` 防止覆盖。
